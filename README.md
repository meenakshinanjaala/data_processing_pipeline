# data_processing_pipeline



## Project Description

This project is a Python-based data processing pipeline. It reads raw student data from a CSV file, cleans the data, handles missing values, converts data types, and creates a cleaned output CSV file.

The project also includes logging and configuration management.

## Features

- Reads raw data from a CSV file.
- Handles missing values.
- Converts age to integer.
- Converts marks to float.
- Handles invalid values.
- Creates a cleaned output CSV file.
- Implements logging.
- Uses configuration management.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

   python main.py

5. Check the `data_pipeline` folder.
6. Open `output.csv` to view the cleaned data.

## Project Files

- `main.py` - Main Python program.
- `input.csv` - Raw input data.
- `output.csv` - Cleaned output data.
- `config.json` - Configuration settings.
- `pipeline.log` - Log file.
- `requirements.txt` - Required packages.
- `README.md` - Project documentation.

## Output

The pipeline processes the input data and generates cleaned student records in the output CSV file.

## Conclusion

This project demonstrates basic data cleaning, type conversion, missing value handling, logging, and configuration management using Python.
